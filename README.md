## 🚀 About The Project

The **Micro-Sponsorship Portal** bridges the gap between passionate creators, students, or community organizers seeking minor funding and small-scale sponsors looking to make a direct, tangible impact. 

This repository contains a full-stack implementation featuring custom Java HTTP handlers, object serialization for data management, and a clean, responsive frontend interface.

---

## 📊 Languages & Tech Stack

* **Frontend:** [JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript), HTML5, CSS3
* **Backend:** Java (Custom HTTP Handlers, Object Serialization)
* **Deployment & Hosting:** Vercel ([Live App](https://microsponsorshipportal.vercel.app))
